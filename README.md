\# X5 Автоторги — автоматическое заполнение ставок



Приложение для автоматического заполнения цен, стран и комментариев в файлах торгов X5.



\## Как работает



1\. Скачайте файл с портала X5

2\. Загрузите его в приложение

3\. Введите скидку (если нужна) и комментарий

4\. Скачайте готовый файл с заполненными ставками



\## Локальный запуск



```bash

pip install -r requirements.txt

streamlit run app.py
